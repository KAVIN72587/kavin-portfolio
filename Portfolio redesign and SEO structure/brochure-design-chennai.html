What arrives at the printer

The difference between a design file and a print file is where most brochure jobs go wrong.

  • CMYK, not RGB

    Converted and checked, so the blues that glow on screen don't come back grey on paper.

  • 3mm bleed and crop marks

    Every edge-to-edge image extends past the trim, so a slight cutting shift doesn't leave a white sliver.

  • 300dpi images

    I check every supplied photo at final size and tell you early if one needs reshooting.

  • Fonts outlined

    No substitution surprises on the press operator's machine.

  • Correct imposition

    Folded formats set up so panel three is actually the panel that faces out first.

  • A press check

    For runs worth it, I'll go and look at the first sheet with you before the run continues.

Brochure design FAQs

How much does brochure design cost in Chennai?+

₹1,500 per page for a straightforward layout with supplied content. Heavy infographics, data visualisation or a bilingual second version are quoted on top. A four-page bifold usually lands around ₹5,000.

Do you write the content too?+

I edit and restructure what you send — cutting, reordering and shortening so each spread holds one idea. Writing from scratch is a separate charge, and I will tell you upfront if the material needs it.

Can you handle Tamil and English in the same brochure?+

Yes, and it is common for retail and government-facing work. Both languages are set at matched optical weight so neither looks like an afterthought.

Will you deal with the printer?+

Yes. I send the file in the format they ask for, answer their queries directly, and for larger runs I will attend the press check with you.

What if my photos aren't good enough?+

I check every image at final print size before layout starts and flag the weak ones early, while there is still time to reshoot. Enlarging a small web image never works in print.

How many revisions are included?+

Two rounds, same as all my work. For multi-page documents, send feedback on the whole document at once rather than page by page — it keeps the layout consistent and the timeline intact.
