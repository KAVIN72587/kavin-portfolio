# Image brief: 22 empty portfolio slots

Use your real client work for every image here. If a client can't be shown, mock up the real deliverable with their name blurred, or remove the tile. Never use stock photos or AI images to stand in for "work".

## Export rules (all images)

- **Format:** WebP, quality 80, sRGB. Aim for **under 150 KB** (existing images are 55–130 KB).
- **Folder:** `Portfolio redesign and SEO structure/assets/slots/`
- **Naming:** lowercase-with-hyphens, e.g. `branding-textile-exporter.webp`
- **Look:** the site is dark (near-black tiles, warm off-white text, yellow accent). Neutral or dark backgrounds sit best; avoid pure white full-bleed.
- **Safe area:** keep the key subject inside the middle ~80%. Tiles have rounded corners and are cropped to fill.
- **Alt text:** send one plain sentence per image describing what's in it.

| Ratio | Export size |
|---|---|
| 1:1 | 1000 × 1000 |
| 4:3 | 1200 × 900 |
| 16:10 | 1440 × 900 |
| 16:9 | 1600 × 900 |
| 21:9 (full-width banner) | 1600 × 686 |

**Shoot once, use twice:** three projects appear on both a category page and the main portfolio page. Textile and clinic use different ratios, so shoot one large master image and export both crops. The Diwali campaign is square in both places, so one file covers both.
